Moodluma｜一般模式四大分類精準修正版
==========================================

本版直接使用客戶目前的 Moodluma(7).zip 修改。

這次不是只修「強烈」一個詞，而是把一般模式首頁圓圈的分類入口整理乾淨。

【1. 類型】
- 類型圓圈只讀真正的 genres / genre / 電影類型欄位。
- genreKeywords / 類型關鍵字保留給搜尋與推薦，但不參與首頁圓圈。
- 類型再經過 genre 語意過濾，只留下真正像電影類型 / 子類型的內容。
- 例如：
  新黑色電影 → 類型
  賭博 → 不再當類型
  旅程 → 不再當類型
  韓國電影 → 不再當類型
  善惡對決 → 不再當類型

【2. 情緒】
- 主要讀 emotions / emotion / mood 類欄位。
- 會再檢查是否真的像情緒。
- 例如：
  節日喜悅 → 情緒
  驚喜 → 情緒
  驚嚇 → 情緒
  珍惜 → 情緒
  荒謬 → 情緒（依客戶刮刮卡的分類規則）
  強烈 → 太模糊，不顯示

【3. 氛圍】
- 主要讀 atmospheres / atmosphere 類欄位。
- 如果資料庫把明顯的氛圍詞放錯到情緒欄位，首頁顯示時會移回氛圍。
- 例如：
  動盪 → 氛圍
  蕭瑟 → 氛圍
  詭異神秘 → 氛圍
  電影感 → 太模糊，不顯示
  想像力豐富 → 太模糊，不顯示
  塵土 → 單獨作為氛圍太模糊，不顯示

【4. 場景】
- 場景仍以 scenesMain / scenesSub 為準。
- 因為實際場景可能有大量不同地點名稱，不用小型白名單硬限制。
- 家庭庭院、家中、計程車、小徑等都會正常保留為場景。

【5. 不修改 FilmDB】
- 原始 FilmDB 資料完全不動。
- 搜尋 / 推薦仍可使用完整 keywords。
- 只有「一般模式首頁 10 顆圓圈」經過這層顯示用語意分類。

【6. 未知詞不再預設為情緒】
舊 classifyTag() 猜不到時會 return "mood"，
現在改成 return null，避免所有無法辨認的詞自動變成粉色情緒。
