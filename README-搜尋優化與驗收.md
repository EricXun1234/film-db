# Moodluma 搜尋改善：驗收與使用說明

版本：2026-10-25。本次以使用者最新提供的 Moodluma.zip 為基礎，未將其他 ZIP 的會員或忘記密碼版本合併進來。

## 本次完成

- 探索頁的手動輸入、分類按鈕、情緒語句按鈕與 results.html 共用 search-rules.js / search-engine.js。
- 48 組搜尋規則，包含既有 32 組分類與新增的常見找片說法，共 224 個觸發詞／句型（不是 224 部電影或 224 個新資料庫標籤）。
- 支援常見的問句與修飾語：「有沒有搞笑電影」「想看點輕鬆的」「今天很累想看輕鬆一點的」。
- 支援正向偏好及否定排除：「想看愛情但不要悲劇」「不要恐怖和血腥」「不恐怖的懸疑片」。不會把「有沒有」當成否定，也不會把「不想動腦」當成排除輕鬆。
- 「愛情或喜劇」依任一條件；「愛情和喜劇」需同時符合。這項或／且規則目前針對已辨識的分類與偏好，未實作任意複雜語句的邏輯解析。
- 搜尋後依相關程度排序，分數相同時依固定欄位排序；同樣資料與設定下不再隨機跳動。未輸入條件的探索首頁仍保留原本隨機預覽。
- 顯示辨識到的想看／排除條件，以及沒有被規則辨識但仍要搜尋的關鍵字。陌生關鍵字不會被偷偷忽略，也不會自動塞入無關結果。
- 補齊獨立搜尋頁的 raw 欄位，讓情緒、氛圍、標籤、演員和導演的搜尋依據一致。保留片名與人名搜尋。
- 標籤推薦也使用同一套同義詞比對，減少文字略有不同就完全找不到的狀況。
- 更新 Service Worker 快取版本及搜尋腳本版本。

## 開啟與操作

1. 將整包 ZIP 解壓縮，雙擊 start-preview.cmd。它會先找 node 指令，找不到時嘗試這台 Codex 附帶的 Node.js 路徑。不會安裝任何程式。
2. 視窗顯示 Open http://127.0.0.1:8080/index.html 後，保持視窗開啟，在同一台電腦用瀏覽器開這個網址。
3. 切到「探索電影」，輸入下面的驗收句子，觀察辨識提示、結果及順序。
4. 獨立結果頁可開 results.html?keyword=想看好笑的，或在結果頁內再次搜尋。
5. 需要部署時，上傳整個資料夾（包含兩個新增搜尋腳本），不要只替換 app.js。若是現有網站仍顯示舊版，重新整理並確認已取得新的 Service Worker／腳本。

此伺服器只在本機 127.0.0.1:8080 提供靜態檔，不會部署。若 8080 被占用，請先關閉之前的預覽視窗。電影資料仍由原本 FilmDB 網址取得；無法取得時，首頁會沿用原專案的示範資料，這不代表正式資料驗收通過。

## 建議人工驗收

| 輸入 | 預期辨識與行為 |
|---|---|
| 想看好笑的／有沒有搞笑電影／想笑一下 | 同一個喜劇搜尋方向，結果與排序相同 |
| 想放鬆一下／今天不想動腦 | 輕鬆／放鬆方向；按鈕與輸入相同句子一致 |
| 今天很累想看輕鬆一點的 | 輕鬆／放鬆方向，不把「很累」當成片名 |
| 想看愛情但不要太悲傷 | 保留愛情，排除悲傷／悲劇標籤 |
| 不要恐怖和血腥 | 排除相關標籤，不把它們當成正向偏好 |
| 不恐怖的懸疑片 | 懸疑方向，排除恐怖 |
| 愛情或喜劇 | 任一方向符合即可 |
| 愛情和喜劇 | 兩個方向都需符合 |
| 有沒有反轉很多的 | 反轉／懸疑方向 |
| 想看甜甜的戀愛 | 甜蜜／浪漫方向 |
| 跟朋友一起看 | 朋友聚會／歡樂方向 |
| 跟小朋友一起看 | 親子／家庭方向，提示需確認分級 |
| 適合睡前看 | 安靜／慢節奏方向 |
| 適合下雨天 | 雨天／沉靜方向 |
| 周星馳的喜劇 | 演員與喜劇皆需命中 |
| 諾蘭的科幻片 | 導演與科幻皆需命中，前提是 API 有導演欄位 |
| 片名、演員或陌生標籤 | 保留文字搜尋，不隨便改成其他分類 |
| 相同句子連續搜尋 | 資料與設定相同時，結果與排序一致 |

## 已執行的驗證

- 41 項搜尋引擎檢查（含 34 句查詢、同義詞一致性、輸入順序顛倒仍同序、未知字不亂配、問句與否定區分、親子提示及 HTML 字串）。
- 使用兩個實際頁面函式，在 DOM 模擬環境比對 34 句查詢的渲染結果與排序，全數一致。
- 6 組原始資料欄位比對，確認兩個頁面的電影正規化後，共用引擎給出一致結果。
- 情緒按鈕與手動輸入同一句的結果一致。
- JavaScript 語法檢查、ZIP 解壓內容與 CRC 檢查。
- 測試電影是自行建立的示意資料，不代表已用正式 FilmDB 的每部電影驗證。
- 本環境的無頭瀏覽器無法啟動，未完成實際瀏覽器端到端或正式線上資料驗收。交付後請依上表在瀏覽器驗收。

若電腦有 Node.js，可執行 node tests/search.test.cjs 重跑 41 項搜尋檢查。

## 後續擴充

只要修改 search-rules.js 的規則即可擴充：triggers 是使用者說法；terms 是正向可命中的電影資料標籤；excludeTerms 是用於排除的較精確標籤。兩個頁面會一起使用。新增後應把範例加入 tests/search.test.cjs 再測試。

這是規則式搜尋，不是可理解所有句子的 AI。電影缺少對應標籤時不會憑空產生；例如「反轉」會搜尋懸疑／推理等相近標籤，並不能保證每部電影都有反轉。「跟小朋友看」也不是分級過濾，正式觀看仍應核對分級。複雜雙重否定、很長的故事、同時指定多個人名的任意或／且條件不在本版保證範圍。

本次沒有新增後端 API，也沒有驗證或改動帳號系統。
